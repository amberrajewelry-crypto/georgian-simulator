# Georgian Language Exam Simulator

სიმულატორი - მოსამზადებელი კურსი ქართული ენის გამოცდისთვის (ს. 32²)

**Features:**
- 200 კითხვა (80 გრამატიკა, 60 ლექსიკა, 60 ტექსტის გაგება)
- ⏱️ 120-წუთიანი ტაიმერი
- 💾 LocalStorage — ავტოსეივ ყველა პასუხი
- 🔴 ფილტრი "მხოლოდ შეცდომები" — გაიმეორე თავი
- ⌨️ Keyboard: Enter=პასუხი, ←→=ნავიგაცია
- 📊 სტატისტიკა სექციების მიხედვით
- 📱 მობილური-ოპტიმიზირებული

**Deploy:** `vercel deploy`

**Local:** Open `simulator.html` in browser (requires `bank.json` same directory)
